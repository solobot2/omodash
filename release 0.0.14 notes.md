# Omodash 0.0.14

- Удалены экспериментальный AA-видеоклиент, PiP, отладочные команды и лишние кнопки настройки/остановки. Убрана симуляция скорости/разгона в Trip Meter. Запись производительности и отправка жалоб с диагностическим ZIP сохранены.
- Android Auto использует штатный приёмник в области плиток через временный помощник, который лаунчер запускает по локальному TCP ADB. Добавлена USB-команда `enable-android-auto`; доступность после перезагрузки зависит от прошивки.
- Масштаб текста и UI: 100–200%, шаг 5%. Масштаб текста применяется также к явно заданным размерам шрифта.
- Сетка виджетов: 6×2 вместо 3×2. Минимальная ширина уменьшена вдвое; сохранённые позиции и размеры переводятся без изменения занимаемой области.
- По умолчанию назначены штатные приложения Omoda 9 HW110: радио/музыка, камера, телефон, Android Auto, CarPlay. Камера вызывает заводской AVM через VDB. Выбранные пользователем приложения сохраняются. Радио больше не просит повторно назначить заводское приложение; дубли кнопок CarPlay/AA удалены.
- Подписанный оптимизированный release APK, versionCode 15; обновляется поверх предыдущих release и локальных dev-сборок до 0.0.13-dev без удаления данных.

Физический автомобиль при подготовке релиза не подключён. Совместимость штатного AA и AVM, аудио и поведение после полного отключения питания требуют проверки на ГУ.
