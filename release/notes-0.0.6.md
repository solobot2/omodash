# Omodash 0.0.6

Первый подписанный релиз этого форка с обновлением прямо из лаунчера.

- Settings → Updates проверяет GitHub Releases, показывает версию, размер APK и изменения.
- Download and install загружает APK через Android DownloadManager и передаёт его системному установщику.
- На Android 11 включённый Omodash Update helper автоматически подтверждает собственное проверенное обновление.
- На Android 12+ сначала используется штатный механизм самообновления без диалога; при запросе подтверждения остаются helper и ручная установка.
- До установки проверяются пакет, версия, совместимость, размер, SHA-256 и совпадение сертификата с установленным приложением.
- Release подписан постоянным ключом и оптимизирован R8. Debug имеет отдельное имя пакета.
- Добавлены Gradle deploy, автоматическое увеличение номера выпуска и публикация APK с update.json, SHA256SUMS.txt и mapping.txt.
- В Settings → Phone integration можно менять и сбрасывать приложения CarPlay и Android Auto. Исправлено долгое нажатие на назначенную плитку.
- Медиакнопка использует Stop для источников без поддержки Pause, включая радио.

## Первая установка

Установить `omodash.apk`, затем разрешить установки из Omodash.
На Android 11 для автоматического подтверждения включить **Omodash Update helper**
в специальных возможностях. Самостоятельно удалять или заменять штатный CarPlay не требуется.

Старый debug с прежним идентификатором пакета имеет другую подпись: его нельзя
обновить новым release без предварительного удаления. Удаление стирает настройки
старого debug. Последующие обновления release сохраняют данные.

## Проверено

- Подписанные оптимизированные APK; полный Android Lint без ошибок.
- Отказ для повреждённого APK и APK с чужой подписью.
- Android 11: загрузка и автоматическое подтверждение A → B; сохранение настройки после обновления.
- Android 15: самообновление без включённой службы специальных возможностей.

Испытание на конкретной прошивке автомобиля ещё предстоит.
