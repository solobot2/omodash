CarPlay и Android Auto теперь можно открыть из меню источников виджета даже при активном радио. Ранее большие кнопки этих приложений показывались только при отсутствии медиаданных. Для штатного Desay CarPlay используется объявленное им действие запуска; ошибки открытия выбранного приложения показываются и записываются в журнал.

В выборе приложения радио появилась кнопка Use the currently playing source as radio: сначала включить штатное радио, затем назначить источник, который уже отображается в Any Player. Открытие медиаплеера использует предоставленный самой медиасессией переход к её экрану, если он доступен.

Кнопки учитывают стандартные команды, заявленные источником. Непредоставленные команды отключены; для источника без стандартного управления есть пояснение. В радио-режиме остановка использует Stop либо Pause согласно возможностям источника. Простое открытие радио больше не отправляет Play автоматически.

Убраны запросы позиции каждые 500 мс для радио без длительности. Для обычных треков опрос прогресса работает только при возобновлённой Activity и прекращается в фоне.

Диагностический ZIP дополнен идентификаторами custom actions и пакетом перехода к экрану медиасессии; нажатия медиакнопок фиксируются с пакетом и объявленными возможностями. Названия станций/треков в диагностические события команд не записываются.

Отображение станций и изменения с руля подтверждены пользователем на автомобиле с 0.0.9. Работа команд управления штатным радио Desay в этой версии ещё не подтверждена: стандартная медиасессия может показывать данные, а управление штатного лаунчера использует отдельный протокол VDB. На эмуляторе проверены UI-сценарии; машину повторно подключать для подготовки этой сборки не требовалось.
