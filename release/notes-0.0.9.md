Однократная USB-настройка прав для Omodash: медиаслужба, установка APK, хелпер автоподтверждения, системные логи и геолокация. Скрипт проверяет результат через PackageManager, NotificationManager, AppOps и Android API приложения. Сетевой ADB, root и смена Device Owner не нужны.

Пять дополнительных кнопок выдачи прав убраны. В настройках остаются статусы; Check updates проверяет доступ к установке и хелперу заново.

В самом начале Settings появились Record logs for 2 minutes и Send / save diagnostic ZIP. Ручная запись ограничена двумя минутами и включает logcat вместе с замерами CPU/памяти. После USB-настройки можно явно включить системные логи. Их вложение в ZIP также требует отметки в форме отчёта; запись сохраняется после выхода из приложения.

USB-команда stop сначала приостанавливает собственные фоновые компоненты, затем выполняет настоящий force-stop и проверяет отсутствие процессов. Ручной запуск восстанавливает компоненты и ранее включённый хелпер. Добавлена диагностика повторного старта после выхода и восстановление регистрации служб на Android 11.

[USB-набор для Mac и Windows](https://github.com/solobot2/omodash/releases/download/v0.0.9/omodash-usb-tools.zip). После распаковки открыть tools/setup-usb.command или tools/setup-usb.cmd; сначала установить этот APK поверх старой версии.

Проверено на отдельном AOSP Android 11, включая запись системного события из другого процесса и исключение системной записи из ZIP без отдельного согласия. Причина ALERT и обрывов радио на автомобиле пока не установлена; этот выпуск даёт инструменты для следующей диагностики.
