Настройка разрешений на автомобильной прошивке без стандартных экранов Android: Configure vehicle permissions подключается только к локальному ADB самого устройства и выдаёт доступ к медиасессиям, обновлениям и журналам только нашему пакету. Может потребоваться однократное подтверждение ключа отладки. Локальный ADB должен быть уже доступен; авторизация не обходится. Android может перезапустить лаунчер при изменении права установки APK. Хелпер обновлений включается отдельно, с сохранением остальных Accessibility сервисов. Кнопки настройки показывают инструкцию вместо пустого действия или системной заглушки.

Скачивание обновления доступно до разрешения на установку; сам APK устанавливается только после выдачи доступа. Добавлен запасной загрузчик для прошивок без Android Download Provider. Все проверки APK и подписи сохранены.

Убран постоянный опрос разрешений каждые 750 мс. В фоне цикл обновлений отменяется; в простое разрешения повторно не опрашиваются. Для исследования ALERT добавлены ограниченные замеры CPU/памяти процесса и журнал смены фокуса. Причина ALERT на автомобиле ещё не подтверждена системными логами.

Подпись в настройках изменена на Made by SolobotWin.

Пояснительный текст и новые элементы управления используют цвета активной темы, включая светлый режим и диалоги.

Добавлена кнопка Stop launcher process: открывает штатный/другой Home и завершает только процесс лаунчера. Если он остаётся домашним приложением по умолчанию, Android может запустить его снова при нажатии Home.
