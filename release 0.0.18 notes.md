# Omodash 0.0.18

- Идентификатор приложения и namespace изменены на `win.solobot.omodash`. Код, тесты, службы, служебные команды и USB-tools используют новый пакет. Имя в Android и интерфейсе — Omodash.
- Новая неоновая иконка OD: у зелёной O скошены только левые углы, правые прямые; оранжевая D имеет плавную внешнюю дугу. На общей вертикали цвета смешиваются. Подготовлены adaptive icons, все Android-плотности, SVG и PNG до 2048×2048.
- USB `setup` восстанавливает права и подключение медиаслужбы, затем пробует включить TCP ADB на порту 5555. Выводятся ответ команды, возврат USB-соединения и состояние adbd; ошибки TCP ADB и прав приложения показываются отдельно. Исправлено распознавание подключённого хелпера по диагностике Android 15.
- Добавлена инструкция запуска USB-tools с Android-телефона через Termux, Termux:API и termux-adb, а также восстановления доступа к медиа через Bugjaeger.
- Панель приложений размещается слева или справа. Нижний вариант переносится влево, нижняя системная строка остаётся видимой для штатных климатических кнопок.

## Установка после смены пакета

Удалить прежний Omodash, установить новый `omodash.apk` и запустить `python3 tools/vehicle_usb.py setup` из нового USB-набора. При необходимости заново выбрать Omodash домашним экраном. Настройки прежнего приложения при удалении теряются. Постоянный сертификат подписи сохранён; дальнейшие обновления нового пакета устанавливаются поверх.

Подписанный production APK, versionCode 19. Код нового пакета, медиаслужба, разрешения и полный USB setup с TCP ADB проверены на Android 15 в эмуляторе. Проверка нового пакета на физическом ГУ ещё требуется.
