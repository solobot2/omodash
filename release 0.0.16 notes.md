# Omodash 0.0.16

- Исправлена неактивная кнопка после скачивания APK без разрешения установки. Теперь доступно действие Allow installation.
- На обычном Android открывается настройка разрешения для Omodash. Если прошивка подставляет заглушку, показывается USB-инструкция с действием Recheck and install.
- После выдачи разрешения повторно используется уже скачанный и проверенный APK. Проверка разрешения выполняется после явного действия пользователя, без постоянного опроса OEM-настроек.
- Статус после завершения скачивания сообщает, что требуется для установки, вместо зависшего сообщения Downloading.

Подписанный production APK, versionCode 17. Обновление сохраняет настройки приложения.
